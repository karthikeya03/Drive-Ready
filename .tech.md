# Step-by-Step Guide: Linking a .tech Domain to AWS and Applying Free SSL

## Part 1: Linking Your Domain to an AWS-Hosted Website

### Step 1: Register a Domain on the .tech Website

1. **Go to the .tech domain provider website** and search for your desired domain name.
   - Complete the registration process, ensuring the domain is active.

### Step 2: Host Your Website Using AWS

You can use two methods to host your site: S3 (for static sites) or EC2 (for dynamic sites). Here's how to set both up.

#### Option 1: Hosting Static Website Using AWS S3

1. **Create an S3 Bucket:**

   - Open AWS S3 in the console.
   - Create a new bucket with a name matching your domain (e.g., `yourdomain.tech`).
   - Ensure the region is closest to your target audience.
   - Under "Permissions," uncheck "Block all public access."
   - Enable static website hosting in the properties tab.

2. **Upload Your Web Files:**

   - Upload your website files (HTML, CSS, JS) to the bucket.

3. **Configure Bucket Policy for Public Access:**

   - Go to the "Permissions" tab, and create a bucket policy to allow public read access:

     ```json
     {
       "Version": "2012-10-17",
       "Statement": [
         {
           "Effect": "Allow",
           "Principal": "*",
           "Action": "s3:GetObject",
           "Resource": "arn:aws:s3:::yourdomain.tech/*"
         }
       ]
     }
     ```

#### Option 2: Hosting a Dynamic Website on AWS EC2

1. **Launch an EC2 Instance:**

   - Go to AWS EC2.
   - Launch a new instance and choose an Ubuntu Server 20.04 AMI.
   - Choose a free-tier t2.micro instance type.
   - Configure key-pair for SSH access.

2. **Install Apache2:**

   - SSH into your EC2 instance:

     ```
     ssh -i /path/to/your-key.pem ubuntu@<your-ec2-public-ip>
     ```

   - Update and install Apache:

     ```
     sudo apt update
     sudo apt install apache2 -y
     ```

   - Place your website files in `/var/www/html`.

### Step 3: Linking Your .tech Domain with AWS Route 53

1. **Create a Hosted Zone in Route 53:**
   - Go to Route 53 and create a hosted zone for your domain (e.g., `yourdomain.tech`).
   - Copy the nameservers (NS) generated.

2. **Update Nameservers on .tech Website:**
   - Log in to your `.tech` domain provider, navigate to your domain settings, and replace the default nameservers with the ones from Route 53.

3. **Create an A Record in Route 53:**
   - In your hosted zone, create a new "A" record pointing to your EC2 instance's public IP or S3 website endpoint.

## Part 2: Applying Free SSL from AWS ACM to AWS Load Balancer (Ubuntu, Apache2)

### Step 1: Create a Free SSL Certificate in AWS ACM

1. **Go to AWS ACM:**
   - Open AWS Certificate Manager.
   - Choose “Request a certificate” and select public certificate.
   - Enter your domain name (e.g., `yourdomain.tech`).
   - Validate the certificate using DNS (recommended) by adding the required CNAME record in Route 53.

2. **Wait for Certificate to Be Issued:**
   - Once validated, the certificate will be issued.

### Step 2: Set Up AWS Load Balancer with SSL

1. **Create an Application Load Balancer:**
   - Go to EC2 and select "Load Balancers."
   - Create an Application Load Balancer.
   - In the "Listeners" section, choose HTTPS (port 443) and select the SSL certificate you generated in ACM.

2. **Configure Target Group:**
   - Create a target group pointing to your Ubuntu EC2 instances running Apache2.

### Step 3: Update Apache to Use SSL

1. **Install SSL module for Apache:**

   - SSH into your EC2 instance:

     ```
     sudo apt install apache2
     sudo apt-get install python3-certbot-apache
     ```

2. **Configure Apache to handle HTTPS:**

   - Modify Apache config files to redirect HTTP to HTTPS and enable the use of the certificate.

3. **Restart Apache:**

   ```
   sudo systemctl restart apache2
   ```

### Step 4: Test and Verify

- Access your website via `https://yourdomain.tech` to confirm the SSL certificate is working.

---

## Conclusion

You have now linked your `.tech` domain to AWS-hosted content and successfully applied SSL using AWS ACM with an Application Load Balancer for an Apache2 web server.
